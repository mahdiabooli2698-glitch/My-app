# دفتر زندگی — نسخه نهایی

اپلیکیشن وب فارسی برای گزارش روزانه، مطالعه، مالی، خواب، کالری، ترید و تحلیل روند.

## امکانات

- تقویم شمسی + میلادی
- گزارش روزانه: خاطره، مالی، مطالعه درسی (نام آزاد + تست + نکات اشتباه)، غیردرسی، ورزش، خواب، کالری، ترید، برنامه ۴ بلوکه، شکرگزاری
- تودولیست با تاریخ شمسی
- استریک فقط بر اساس مطالعه درسی
- خلاصه هفتگی (هفته‌های ۱–۷، ۸–۱۴، ۱۵–۲۱، ۲۲–۲۸) با تحلیل روند و نمودار
- خلاصه ماهانه ۱۲ ماه با انتخاب سال + تحلیل روند سالانه
- آمار درس‌به‌درس، دخل/خرج/پس‌انداز، مانده پول
- جمله انگیزشی علمی روزانه (شامل نوروپلاستیسیته)
- نکات علمی چرخشی در صفحات هفته و ماه
- PWA (قابل نصب روی موبایل)
- خروجی/ورود JSON و mailto

## اجرا

فایل `index.html` را در مرورگر باز کنید. برای نصب روی اندروید: Chrome → Add to Home screen.

## نکته

داده‌ها فقط روی دستگاه شما (localStorage) ذخیره می‌شوند.
